### 5.1 UI 操作路径编写规范

格式为 `[页面名称] → 动作 → [页面名称] → 断言`，自然语言描述，AI 测试引擎可自动理解并执行：

```
动作类型：
  点击"按钮文案" | 长按"元素文案" | 输入"内容"
  选择"选项" | 滑动到"区域" | 等待{毫秒}ms | 截图

断言关键字：
  页面显示"文案" | 页面不显示"文案" | Toast显示"文案"
  弹窗显示"文案" | 元素"文案"状态为"勾选/未勾选" | 输入框"文案"内容为"值"
```

> 项目经确认无 UI 自动化测试时，UI 操作路径列标注"无 UI 自动化测试"即可跳过。
